# Insta Design Clone v2 / نسخة التصميم

## English

A Flutter 3.22+ demo that recreates an Instagram-inspired design with onboarding, authentication mock, localization (Arabic default), dark mode, pull-to-refresh, pagination, and a design system showcase.

### Quick Start
1. Ensure Flutter SDK 3.22.0 or newer is installed.
2. Run `flutter pub get`.
3. Launch with `flutter run`.

## العربية

تطبيق تجريبي بفلاتر 3.22+ يحاكي تصميم إنستغرام مع شاشات تعريف، تسجيل دخول تجريبي، تعدد اللغات (العربية افتراضيًا)، الوضع الليلي، سحب للتحديث، تحميل متدرج، وصفحة نظام تصميم.

### خطوات التشغيل
1. تأكد من تثبيت فلاتر 3.22.0 أو أحدث.
2. نفّذ `flutter pub get`.
3. شغّل التطبيق عبر `flutter run`.
